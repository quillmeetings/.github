## Quill

**Your AI Chief of Staff** — from conversation to execution.

Quill captures your meetings, transcribes them with multi-speaker precision, and
turns them into notes, answers, and follow-ups. No bot joins your calls: Quill
runs on your own device and captures audio at the system level, so it works
offline and **your data stays yours**.

- 🌐 [quillmeetings.com](https://quillmeetings.com)
- 📥 [Download Quill](https://quillmeetings.com/download)

### Open source & integrations

Most of our work lives in private repos, but here's what's public — build on Quill
with the CLI and our Claude Code integrations:

- **[quill-cli](https://github.com/quillmeetings/quill-cli)** — CLI for Quill, backed by the local Quill MCP server
- **[claude-plugins](https://github.com/quillmeetings/claude-plugins)** — Quill's Claude Code plugin marketplace
- **[claude-skill-quill-deep-analysis](https://github.com/quillmeetings/claude-skill-quill-deep-analysis)** — Claude Code skill: deep map/reduce research over your Quill meeting corpus
